# Реальные данные — юридические правила

С этой версии проект использует РЕАЛЬНЫХ футболистов, клубы и стадионы
(решение пользователя, явно подтверждено — разворот от прежней вымышленной
вселенной). Правила обязательны всегда:

- Используем только: имя игрока, позицию, национальность (текст/флаг-эмодзи),
  название клуба текстом, числовые характеристики, факты о стадионе
  (название/город/вместимость/год постройки).
- ЗАПРЕЩЕНО: реальные фото игроков, эмблемы/логотипы клубов и лиг, слова
  FIFA/EA/FC/Ultimate Team/FUT в названии и текстах, копирование визуального
  стиля карточек EA, фото стадионов или детальное воспроизведение их
  архитектуры.
- Вместо фото — собственная процедурная графика: `PlayerPortrait.tsx`
  (абстрактный силуэт), `ClubCrest.tsx` (процедурный геральдический щит),
  `StadiumIllustration.tsx` (абстрактная чаша трибун).
- Рейтинг и суб-статы — собственная формула (`prisma/seedShared.ts`), не
  копия рейтингов EA.
- `prisma/data/clubs.json` и `prisma/data/players.json` — курируемый набор,
  обновлять вручную по мере необходимости (составы/трансферы меняются).
